Employee Salary Prediction — Web App
A machine learning pipeline that predicts employee salary from profile
data (experience, education, job title, department, location), served
as a Flask web application with a performance dashboard and a live
prediction form.
How it works
```
Generate synthetic   Clean &        Cross-validate      Evaluate on      Serve via
employee dataset  -> engineer   ->  3 regression     ->  held-out    ->  Flask web app
                     features       models, pick best    test set        (dashboard + form)
```
generate_data.py — creates a synthetic employee dataset (age, gender,
education, job title, department, location, experience, tenure) where
salary is built from a realistic formula plus noise. Gender is
included but deliberately given no effect on salary, so a
well-trained model should learn to ignore it — a good sanity check
printed right on the dashboard.
preprocessing.py — scales numeric features and one-hot encodes
categorical ones.
train_model.py — cross-validates Linear Regression, Random Forest,
and Gradient Boosting on R², picks the best, and saves the fitted
pipeline.
evaluate.py — computes MAE, RMSE, R², and MAPE on the test set, and
saves three charts: actual-vs-predicted, residual distribution, and
feature importance.
predict.py — batch-scores a CSV of employee records from the
command line.
app.py — the Flask web app.

Setup
```bash
cd salary_prediction
pip install -r requirements.txt
```
Reproduce the pipeline (optional — a trained model is already included)
```bash
cd src
python generate_data.py --n 3000        # regenerate the dataset
python train_model.py                    # cross-validate & save the best model
python evaluate.py                       # compute metrics & save charts
```
Run the web app
```bash
cd src
python app.py
```
Open http://localhost:5003.
Dashboard (`/`) — MAE/RMSE/R²/MAPE, a comparison of all three
candidate models, actual-vs-predicted and residual charts, and the
feature importance ranking.
Predict Salary (`/predict`) — enter an employee's profile and get
a predicted salary with the key factors behind it.
Results (on the included trained model)
Metric	Value
R² score	0.975
MAE	~$4,960
RMSE	~$6,160
MAPE	~4.4%
Linear Regression won model selection — the underlying salary formula
is mostly additive, so a linear model fits it about as well as more
complex ones, and trains in a fraction of the time.

Notes and limitations
The dataset is synthetic, generated by `generate_data.py` from a fixed
formula plus noise — it's meant to demonstrate the pipeline, not to
reflect real-world compensation data.
Gender and job title are included as features so the project can
demonstrate a fairness-relevant point: the trained model correctly
assigns gender near-zero importance, since it was given no real
effect on salary in the data generator.
This is a single-user demo app with no authentication — don't expose
it directly on the public internet without adding that.
